Running the R cross-check in RStudio

The app can write an R script that rebuilds your analysis independently from your data file and prints the app's results next to R's. This guide takes you from the button in the app to reading the comparison, in about ten minutes the first time.

What you need

  • R (version 4.1 or later) and RStudio, both free. If R.version.string prints a version in the RStudio Console, you are ready.
  • The CSV file you analysed in the app, unchanged and with the same name.
  • An analysis in Step 4 that includes the logistic / linear regression (GLM), or a time-to-event (Cox or competing-risk) model. Random forests, boosted trees, neural networks and k-NN have no identical R counterpart.

The script contains no patient data: only your settings, the row numbers of the Testing set and the app's results. It can be shared with a statistician or kept with your study records.

Step by step

1

Download the script from the app

After training in Step 4, click R cross-check script:

  • yes/no or numerical outcomes: in the row of report buttons above the results, next to Printable report;
  • time-to-event outcomes: under the results, next to Download Survival Analysis Report.

Your browser saves a file named like crosscheck_medical_shunt_cohort_large_2026-10-19.R, usually in Downloads.

2

Put the script and the data file in the same folder

The script looks for the data file next to itself. Its first lines show the exact name it expects, after data_file =.

For the built-in demo cohorts, the CSV files are in the app folder in iCloud Drive (anti-gavity › universal-medical-ml-predictor v2), so the simplest route is to move the .R file into that folder. They can also be downloaded from the website:

For Option B, put the validation file in the same folder too.

3

Install the R packages (first time only)

In RStudio, click in the Console (bottom left), paste this line and press Enter. It takes a few minutes; you never need to repeat it.

install.packages(c("survival", "pROC", "rms", "riskRegression", "prodlim", "mice"))

If RStudio asks whether to install from source, answer No.

4

Open the script and click Source

  1. In RStudio, choose File › Open File… and select the .R file. It opens in the top-left pane.
  2. Click Source at the top right of that pane, or press Cmd Shift S on a Mac (Ctrl Shift S on Windows).

Do not use Import Dataset. The script reads the CSV file itself. A run takes from a few seconds to about a minute (longer for Option C, which repeats the analysis on resampled cohorts).

5

Read the comparison

The Console shows a table headed Cross-check of the app's analysis in R. To show it again at any time, or to open it as a spreadsheet-style tab with all its columns:

print(RES)
View(RES)

How close should they be?

Rows labelled same model as the app compare like with like. Rows labelled standard glm or lm show R's usual unpenalised model, so small differences there are expected.

AnalysisExpected agreement

A large difference means the two analyses are not the same: check the data file and the settings before relying on either result.

Reporting it

When the key numbers agree, the methods section can say so. Run this to see your exact R and package versions:

sessionInfo()

For example: “Model performance was reproduced independently in R (version 4.6; packages survival, pROC, rms, riskRegression) using a script generated by the software; the apparent AUC was 0.803 in both, and the optimism-corrected AUC 0.770 in the software and 0.767 in R.”

The cross-check covers yes/no, numerical and time-to-event outcomes, with Options A, B and C. Outcomes with more than two categories are not covered. Research and education use only.
